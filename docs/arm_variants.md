# 杆长探索方案

以原始RM26独立机械臂为基线。J1表示j1_link上从J1到J2的长杆，保留两端安装件；从中段沿长杆轴切除一段并将远端平移拼接，保持横截面尺寸。同步修改外观、碰撞几何、J2在J1系中的位置，下游坐标保持局部定义，随J2整体移动。禁止仅改关节间距而保留旧碰撞网格。

支持J1、J4、J5、J6的中段裁切和轴向拉伸，并允许不同杆件组合。J5沿局部−Z、以原始0.0755m轴向关节间距计算比例、保留0.012369m横向偏置。J1轴向取J1→J2位移在J1局部XY平面中的方向，保留轴向之外的关节偏置。碰撞网格按原凸块分别裁切封口或沿轴向拉伸，不将整根杆重新包成单一凸包。质量/惯量不重估，仅用于当前运动学及碰撞规划，不用于动力学结论。

每个批次冻结原始/变体模型及所有引用网格，记录配置、修改前后关节偏移、模型/网格SHA256、组合指纹。运行、重算、UI始终使用该批次模型，资源变化拒绝重算。旧批次显示原始/历史未记录指纹，不能追认其精确历史模型。

比较时固定seed、样本、停车网格、朝向、预算、碰撞开关、起始关节角。建议先原始、J1缩短0.05m、0.10m，分别运行相同quick子集检查几何与装配，再full比较任务分、适应分和失败原因；不将不同设置结果直接归因于杆长。

## 2026-11-05 杆长搜索结果

- 将生成器扩展为每根受支持连杆可缩短或轴向拉伸，并支持多杆组合；对配置中的净总轴向长度变化强制限制在原始四段合计长度的±30%。拉伸同步变形外观与每个碰撞凸块，并移动下游关节；J6变体还同步移动能量单元挂载点。
- 原始J1/J4/J5/J6轴向总长为0.790394m，+30%上限为0.237118m。对照基于相同seed、50个核心位姿、9个停车点、每例30s预算和8 workers；完整批次均为450项。
- 最佳方案为只将J1轴向加长0.237118m，净总杆长增加30%。完整结果：任务分均值3.6711/4，适应分8.24/9，373/450项完成全部验收。基线为1.8556/4、2.02/9、47/450。J1加长0.23m的对照为3.6067/4、8.04/9、367/450。
- 上限方案相对基线，372项得分上升、48项持平、30项下降；50个任务中适应分有47个提升、2个持平、1个下降。失败原因从254项预算/迭代未完成、82项能量单元—机械臂碰撞、66项机械臂—核心碰撞，变为12、13、51项。
- 10个分层核心位姿的快速筛选中，J1加长15cm、20cm、23cm和总长+30%均分依次为2.5667、3.3000、3.5333、3.5444；J1加长23cm加J5缩短10%或20%没有超过单独J1加长30%上限方案。
- 完整输入、模型快照、逐例结果及汇总见 `artifacts/rod-length-search-20261105/`；汇总报告为 `artifacts/rod-length-search-20261105/report.md`。
- 结果仍受当前固定抓持、离散碰撞模型和有限求解预算约束。轴向拉伸保留原质量/惯量，只用于当前运动学和碰撞规划，不构成动力学或制造验证。
